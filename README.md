## How to use · Comment utiliser · Cómo utilizar · Como utilizar · Come utilizzare

### 🇺🇸 English

**What is SciSummarize?**  
SciSummarize reads any English-language scientific manuscript and produces an accurate translation of the abstract, a 2–3 paragraph summary, and 10 key findings — all in the language of your choice, with precise scientific terminology.

**Step-by-step instructions:**

1. **Open the tool** — go to https://bhaley1.github.io/manuscript-summarizer---beta
2. **Upload your manuscript** — drag and drop a PDF onto the upload area, or click to browse your files. You can also paste the manuscript text directly into the text box.
3. **Select your language** — click one of the five language buttons: English, Français, Español, Português, or Italiano. Results will always appear in English alongside your chosen language.
4. **Click Summarize** — the button will show a loading animation while the manuscript is being analyzed. This typically takes 15–45 seconds depending on the length of the paper.
5. **Review your results** — three sections will appear:
   - **Abstract** — the original abstract extracted verbatim, alongside an accurate translation
   - **Summary** — a 2–3 paragraph narrative summary of the paper's key findings, methods, and conclusions
   - **10 Key Points** — a bulleted list of the most important findings, with references to specific Tables and Figures where relevant
6. **Copy your results** — click **"Copy all as text"** in the top right of the results section to copy everything to your clipboard for pasting into a document or email.

**Tips:**
- Text-based PDFs work best. Scanned or image-only PDFs may not extract correctly — if results look wrong, try copying and pasting the text instead.
- The tool works best with complete manuscripts. Abstracts alone will produce generic results.
- Scientific terms that have no equivalent in the target language are kept in English.
- Always verify translations against the original manuscript before citing or sharing.

**Supported file types:** `.pdf`, `.txt`, `.md`

**Supported languages:** English · Français · Español · Português · Italiano

## For developers · Pour les développeurs · Para desarrolladores · Para programadores · Per gli sviluppatori

SciSummarize is open source. The architecture uses a static GitHub Pages frontend calling a Cloudflare Worker proxy that securely holds the Anthropic API key.

**Stack:** HTML/CSS/JS · Cloudflare Workers · Anthropic Claude API (`claude-sonnet-4-5`) · Google Analytics

**To deploy your own instance:**
1. Clone this repository
2. Create a Cloudflare Worker from `worker.js` and set your `ANTHROPIC_API_KEY` secret
3. Update `API_ENDPOINT` in `index.html` with your Worker URL
4. Update `ALLOWED_ORIGIN` in `worker.js` with your GitHub Pages domain
5. Enable GitHub Pages on the repository (Settings → Pages → Deploy from branch → main)

**Costs:** GitHub Pages is free. Cloudflare Workers free tier covers 100,000 requests/day. Anthropic API costs approximately $0.01–0.03 per manuscript.
